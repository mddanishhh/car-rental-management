# Car Rental Management System

A web-based car rental management application built with HTML, CSS, and JavaScript. This system allows users to browse available cars, manage bookings, register/login, and provides an administrative interface for managing operations.

## 🚀 Features

- **User Authentication:** Secure user registration and login pages (`register.html`, `login.html`).
- **Car Catalog:** Browse available cars with details (`cars.html`).
- **Booking System:** Seamlessly book vehicles (`booking.html`) and view personal reservation history (`my-bookings.html`).
- **Admin Dashboard:** Administrative panel (`admin.html`) to oversee rentals and management tasks.

## 📁 Project Structure

- `index.html` - Landing page / Home
- `cars.html` - Available vehicles catalog
- `booking.html` - Vehicle reservation page
- `my-bookings.html` - User booking history
- `login.html` & `register.html` - User authentication pages
- `admin.html` - Admin control panel
- `css/` - Stylesheets
- `images/` - Car and UI assets
